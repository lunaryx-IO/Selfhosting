# Begleitmaterial zur Linux-Server-Reihe

**Linux-Server – Das umfassende Praxisbuch · Materialstand 20. Oktober 2026**

Wählen Sie den Band, mit dem Sie gerade arbeiten. Jedes Paket lässt sich für sich entpacken und benutzen. Die vollständigen Arbeitsvorlagen stehen als bearbeitbare Dateien bereit; die Bücher behalten die Erklärungen und Prüfungen, die Sie während eines Arbeitsablaufs benötigen.

Entpacken Sie das gewünschte ZIP in einen neuen Ordner. Öffnen Sie im enthaltenen Bandordner (`band-1`, `band-2` oder `band-3`) die Datei `README.md`. Die Texte mit der Endung `.md` lassen sich in einem gewöhnlichen Texteditor lesen und bearbeiten. Speichern Sie ausgefüllte Vorlagen als eigene Arbeitskopien.

Die Materialfassung **2026.10.20-r2** gehört zur aktuellen Linux-Server-Dreierreihe. Die beiliegende `VERSION.md` ordnet jedes Paket zu und beschreibt den Prüfstand. Die [frühere Webhosting-Fassung 2026.10.12-r4](https://github.com/lunaryx-IO/Selfhosting/releases/tag/material-2026.10.12-r4) bleibt als eigene ältere Ausgabe erhalten.

Die [öffentliche Materialübersicht](https://github.com/lunaryx-IO/Selfhosting) ist die gemeinsame Anlaufstelle für Downloads und spätere Korrekturen.
