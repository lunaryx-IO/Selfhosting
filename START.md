# In wenigen Schritten zum passenden Material

Die Unterlagen lassen sich direkt im Browser lesen. Wenn Sie eigene Notizen ergänzen oder die Beispieldateien verwenden möchten, laden Sie das Paket Ihres Bandes herunter.

## 1. Den eigenen Band wählen

Die Fassung **2026.10.26-r2** gehört zur Verkaufsfassung vom 26. Oktober 2026 von **Linux-Server – Das umfassende Praxisbuch**:

- [Band 1 herunterladen](linux-server_2026-10-26-r2/pakete/Linux_Server_Band_1_Begleitmaterial_20261026_r2.zip?raw=true): Werkstattwebsite, Betriebsheft, DNS-Übung, geschützte Proxyprobe und Quellen.
- [Band 2 herunterladen](linux-server_2026-10-26-r2/pakete/Linux_Server_Band_2_Begleitmaterial_20261026_r2.zip?raw=true): vollständiges Betriebsheft mit Kostenbeispielen, Diagnosefälle, Terminprüfung, KI-Arbeitsfälle mit erklärten Lösungen und Quellen.
- [Band 3 herunterladen](linux-server_2026-10-26-r2/pakete/Linux_Server_Band_3_Begleitmaterial_20261026_r2.zip?raw=true): Betriebsheft für Dateien und Postfächer, vier Diagnosefälle, zwölf Kopiervorlagen, Kostenplanung und Quellen.

Die Links laden das jeweilige ZIP direkt herunter. Ein GitHub-Konto benötigen Sie dafür nicht. Entpacken Sie das ZIP in einen neuen Ordner; Ihre bereits ausgefüllten Arbeitsdateien bleiben so erhalten.

## 2. Mit der README im Bandordner beginnen

Im Archiv finden Sie den Ordner `band-1`, `band-2` oder `band-3`. Öffnen Sie darin `README.md`. Sie führt zu den passenden Dateien. Die Endung `.md` bezeichnet gewöhnlichen Text mit einfachen Formatierungszeichen; ein Texteditor genügt. Im GitHub-Browser werden Überschriften, Listen und Tabellen bereits formatiert dargestellt.

Die mitgelieferte `VERSION.md` nennt den zugehörigen Buchstand. Kapitelnummern beziehen sich auf den dort genannten Band. Speichern Sie ausgefüllte Vorlagen als eigene Arbeitskopien.

## 3. Die passende Aufgabe auswählen

Das Betriebsheft begleitet Ihren eigenen Aufbau. Die Diagnosefälle lassen sich zunächst ohne Server durchdenken. Website-Dateien und Kopiervorlagen verwenden Sie an der jeweils genannten Stelle im Buch. Dort stehen die Voraussetzungen, Ihre eigenen einzusetzenden Werte, die Prüfschritte und der Rückweg.

Ihre persönlichen Zugänge, Schlüssel und echten Kundendaten bleiben in ihrer geschützten Ablage. Die Beispiele im Begleitmaterial arbeiten mit erfundenen Werkstattdaten.
