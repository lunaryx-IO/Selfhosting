# In wenigen Schritten zum passenden Material

Die Unterlagen lassen sich direkt im Browser lesen. Wenn Sie eigene Notizen ergänzen oder die Beispieldateien verwenden möchten, laden Sie das Paket Ihres Bandes herunter.

## 1. Den eigenen Band wählen

- [Band 1 herunterladen](pakete/Webhosting_Band_1_Begleitmaterial.zip): Website, Betriebsheft, DNS-Übung, geschützte Proxyprobe und Quellen.
- [Band 2 herunterladen](pakete/Webhosting_Band_2_Begleitmaterial.zip): Anwendungen, Diagnosefälle, Terminprüfung, KI-Aufgaben mit gleichwertiger Lösung ohne KI und Quellen.

GitHub zeigt bei einer ZIP-Datei gegebenenfalls zuerst die Dateiansicht. Über das Download-Symbol oder **Download raw file** laden Sie das Archiv herunter. Entpacken Sie es in einen neuen Ordner. Ihre bisherigen Arbeitsdateien bleiben dabei erhalten.

## 2. Mit der README Ihres Pakets beginnen

Die Datei `README.md` ist der Wegweiser. Die übrigen Dateien mit der Endung `.md` sind gewöhnlicher Text mit einfachen Formatierungszeichen. Ein Texteditor genügt; im GitHub-Browser werden Überschriften, Listen und Tabellen bereits formatiert angezeigt.

Kapitelnummern beziehen sich auf den jeweils genannten Band. Die Kennungen K012 oder BL04 sind zusätzliche Zuordnungshilfen: K bezeichnet einen Kapiteltext, BL eine Beilage. Zum Arbeiten brauchen Sie diese Kennungen nicht auswendig zu lernen.

## 3. Die passende Aufgabe auswählen

Das Betriebsheft begleitet Ihren eigenen Aufbau. Die Diagnosefälle lassen sich zunächst ohne Server durchdenken. Die Website- und Proxydateien sind vollständige Vorlagen aus dem Buch; verwenden Sie sie erst an der dort beschriebenen Stelle. Eine Konfigurationsdatei wird nicht allein durch ihren Download zur passenden Konfiguration für Ihren Server.

## Wenn Sie das Buch probelesen

Öffnen Sie den [Testleser-Leitfaden](mitmachen/README.md). Er erklärt, welche Buchstellen und Dateien Sie benötigen, woran Sie das Ergebnis erkennen und wie Sie eine unklare Stelle festhalten. Ihre Rückmeldung darf kurz sein. Besonders hilfreich ist der Satz, an dem Sie nicht mehr wussten, was als Nächstes zu tun ist.
